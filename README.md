# Backend Server Side Program

### Setup - Server ready

- core nodejs
- Express (Framework)

### Package Manager used in Project - pnpm

- To install `pnpm` in project following steps should be followed:
  - npm i pnpm -g (global dependency)
  - pnpm init

### E-Commerce Features:

- Authentication
  - Register
  - Login
  - Activate User
  - Forgot Password
  - Reset Password
  - Logout User
